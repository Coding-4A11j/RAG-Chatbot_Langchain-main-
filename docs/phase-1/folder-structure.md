# SalesGenius AI — Phase 1 Enterprise Folder Structure

## Required Top-Level Structure
- `frontend/`
- `backend/`
- `ai/`
- `shared/`
- `docs/`
- `docker/`
- `nginx/`
- `.github/`
- `scripts/`
- `infra/`

## Standards by Area
- `frontend/`: app routes, feature modules, UI system, client state/query layers.
- `backend/`: API routers, service layer, repositories, schemas, migrations, workers.
- `ai/`: agent graphs, tool adapters, retrieval pipelines, model/provider abstractions.
- `shared/`: DTO contracts, validation schemas, shared enums and constants.
- `docs/`: architecture, guides, phase records, changelog.
- `docker/` and `nginx/`: container/runtime and ingress configuration.
- `.github/`: CI/CD workflows, templates, automation policies.
- `scripts/`: reproducible local/devops helper scripts.
- `infra/`: environment provisioning and deployment infrastructure code.
